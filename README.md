# 紙飛機實驗室 ✈️

👉 **直接玩：<https://chiux125.github.io/paperplane/>**（不用安裝，打開瀏覽器就能玩）

在電腦上自由摺一張紙飛機，看看它的重心在哪裡、空氣怎麼流過機翼，猜猜它會不會飛得穩——然後**用真的紙摺一架一模一樣的，射射看，對對答案！**

這是一個家長和孩子一起做出來的小工具。畫面上的計算都只是「示意」，最後以實際射出為準：猜錯了也沒關係，想想為什麼，才是最好玩的地方。

## 怎麼玩

1. **📐 摺紙**：從一張白紙開始，用「畫線」「點對點」「邊對邊」摺出你的飛機。左右會自動一起摺；摺錯了按「復原」。最後按「對摺」。
2. **✈️ 看飛機・風洞**：轉一轉 3D 飛機，調整機翼的位置和角度、夾上迴紋針。紅點是重心、藍點是升力中心，看看它說你的飛機「穩穩的」還是「容易仰頭」。點一下翼片，還可以把它翹起來。
   再看看煙怎麼流過機翼：把攻角（機頭抬起的角度）慢慢調大，看什麼時候「失速」；按「推一下」看飛機會不會自己轉回正。
3. **📏 射射看**：用真的紙摺同一架飛機去射，把飛了多遠、怎麼飛的記下來，和工具的預測比一比。記得每次都用同樣的方式射。

💾 可以把摺好的飛機存成檔案，下次再打開繼續玩。

**建議用電腦（滑鼠）玩**；平板也能用，但操作手感還沒有特別調整。射紙飛機時不要對著人或動物喔！

## 給家長

- **不收集任何資料**：沒有帳號、沒有廣告、沒有追蹤。飛行紀錄只存在你自己的瀏覽器裡，不會傳到任何地方。
- 這不是精確的空氣動力學模擬，而是幫孩子「看見」設計好壞原因的預測工具；真正的答案在實際射出的那一刻。

## 開發

```sh
npm install
npm run dev        # 開發伺服器
npm test           # 單元測試
npm run build      # 型別檢查＋打包（輸出到 dist/）
```

推上 `main` 後，GitHub Actions 會自動跑測試、打包並部署到 GitHub Pages（`.github/workflows/deploy.yml`）。

開發進度與計畫見 [docs/ROADMAP.md](docs/ROADMAP.md)，最近的實作細節見 [docs/HANDOFF.md](docs/HANDOFF.md)。

### 結構

- `src/core/`：核心，純函式、不碰 DOM，都有單元測試
  - `geom/`：向量、直線、等距變換、凸多邊形運算
  - `model/`：面（Face）、鉸鏈（Hinge）、層序（Orders）、紙張狀態
  - `engine/`：兩個基本動作 `splitFaces`（沿線切開）與 `moveFaces`（分組移動＋指定層序）
  - `planners/`：把使用者的意圖換算成基本動作（簡單摺、鏡像摺、翻面、反摺…）
  - `construct/`：三種摺法的摺線（自由畫線、點對點、邊對邊）與吸附
  - `physics/`：3D 組裝、重心、升力中心、穩定度、翼片翹起、風洞流場
  - `validate/`：合法性檢查（凸性、撕裂、層序、穿紙）
  - `history.ts`：可重播的操作紀錄、復原／重做
  - `io/`、`log/`：FOLD 存檔、飛行紀錄
- `src/ui/`：介面（Preact＋Canvas＋Three.js）
- `tests/`：核心的單元測試

座標單位是 mm。原紙座標 x ∈ [-寬/2, 寬/2]（x = 0 是機身中線），y ∈ [0, 高]（y = 高 是機頭）。
